# Olsenbygg Grimstad – konsept for ny nettside
**Uavhengig konsept – ikke bestilt eller godkjent av Olsenbygg Grimstad AS.** Offisiell side: https://www.olsenbygg.com

Statisk side (GitHub Pages, ingen byggesteg), laget etter samme oppskrift som [odegarden](https://tussienorway.github.io/odegarden/).
- `index.html` – forside med tre innganger (privat/næring/offentlig), Sci-Fi Lab-teaser, før/etter-glider (KI-illustrasjoner), EKSEMPEL-plassholdere, kart som lastes på forespørsel, kontakt med åpningstider.
- `scifi-lab.html` – tomtevisualisering (demo: tekstur på markert område; KI via proxy) + mengde/grovestimat.
- `materialer.html` – internt materialverktøy (localStorage, EKSEMPELDATA).
- `server/` – proxy for xAI Grok bildeedit, nøkkel i `XAI_API_KEY`. Deployes ikke.

Regler: Tekst merket EKSEMPEL er plassholdere. Priser er eksempelestimat. API-nøkler skal aldri ligge i nettleseren, bare i en proxy.
Fakta og kilder: `js/data.js` (hentet 02.11.2026). Åpningstider og koordinater er fra tredjepart og ikke bekreftet.
